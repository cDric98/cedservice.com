Le code promo se saisit une seule fois, à l'inscription. C'est ensuite votre premier dépôt, fait chez nous, qui déclenche le bonus de bienvenue.

Vous n'avez pas encore de compte

  1. Inscrivez-vous sur 1xBet. Choisissez l'inscription par téléphone ou par e-mail et sélectionnez le franc CFA (XOF) comme devise.
  2. Saisissez le code CECE dans le champ « Code promo » du formulaire, avant de valider. Il ne peut pas être ajouté après.

Vous avez déjà un compte

Le code d'inscription ne s'applique plus à un compte existant, et il est interdit d'ouvrir un deuxième compte pour en profiter : le bookmaker peut bloquer les deux.

Vous pouvez tout de même recharger chez nous aux mêmes conditions. Surveillez la rubrique « Promotions » de votre compte : certaines offres de dépôt s'activent avec un code saisi au moment du dépôt.

Recharger maintenant

Les montants de bonus, la mise à rejouer et les dates de validité sont fixés par le bookmaker et changent régulièrement. Lisez les conditions sur son site avant votre premier dépôt.

    Combien de temps prend une recharge ?
    En général 5 à 15 minutes après réception de votre paiement. En cas de forte affluence ou de problème réseau Mobile Money, cela peut prendre plus longtemps ; nous vous prévenons sur WhatsApp.
    
      
    Où trouver mon ID de compte 1xBet ?
    Ouvrez l'application ou le site, connectez-vous puis allez dans « Mon compte ». L'ID est le numéro affiché sous votre nom. Ne communiquez jamais votre mot de passe : il n'est pas nécessaire pour une recharge.
    
      
    Comment utiliser le code promo CECE ?
    Le code se saisit une seule fois, au moment de l'inscription, dans le champ prévu à cet effet. Les conditions du bonus (montant, mise à rejouer) sont fixées par le bookmaker et peuvent changer : vérifiez-les sur son site avant de déposer.
    
      
    Combien de temps prend un retrait ?
    En général moins de 30 minutes après réception du code de retrait, de 8 h à minuit (les demandes reçues entre minuit et 8 h sont traitées à partir de 8 h). Si 1xBet n'a pas encore validé la demande de votre côté, nous vous prévenons et attendons la validation avant de payer.
    
      
    J'ai payé mais je n'ai pas reçu mon crédit.
    Envoyez-nous la référence de la transaction Mobile Money sur WhatsApp. Nous vérifions et créditons ou remboursons.
    
      
    Êtes-vous un partenaire officiel de 1xBet ?
    Oui. Cedservice est partenaire officiel de 1xBet, point de vente (PDV) n° 1506435, pour les dépôts, les retraits et le code promo CECE. Lors d'un retrait, vérifiez que 1xBet affiche bien le nom Cedservice et ce numéro. Nous ne vous demanderons jamais votre mot de passe : votre ID de compte suffit pour toutes les opérations.
